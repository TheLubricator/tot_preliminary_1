================================================================================
ANALYSIS OF WHY THIS HAPPENS
================================================================================

ROOT CAUSE: Prompt Ambiguity

The prompt says:
"Evaluate BRIEFLY then answer with ONE WORD on a new line."

But LLM interprets this as:
"Show your work briefly, then give the answer word"
(NOT: "Only say one word")

For IMPOSSIBLE cases, LLM is extra compelled to:
- Show exhaustive proof that it's truly impossible
- Enumerate ALL operations to prove coverage
- Include multiple verification passes
- Use verbose reasoning to justify "impossible"

For SURE/LIKELY cases, response is shorter because:
- LLM can stop after finding a working solution
- No need to prove exhaustively

Result: IMPOSSIBLE cases generate 4.18x response bloat
        SURE cases probably 1.5-2.0x response size

1. MODIFY PROMPT to enforce brevity:
